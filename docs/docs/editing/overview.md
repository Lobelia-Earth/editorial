# Overview

Editorial provides a default set of tools for editing content in the form of an online dashboard. You should have configured or have been given a URL and credentials to sign in to your website's admin panel. When navigating to the URL you will be greeted with a login interface.

After logging in with your credentials you will be faced with the main Editorial dashboard. Through this you can interact with your content, edit it, and publish new content. On the sidebar you will find links for [Collections](/concepts/collections), [Singles](/concepts/singles), [Files](/concept/files), and [Custom Components](/concepts/custom-components).
