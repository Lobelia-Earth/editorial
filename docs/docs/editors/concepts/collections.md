# Collections

Collections are groups of content that follow the same pattern. A collection could be a `Page` or a `Team Member` and have many different entries. This is a stark opposite of [Singles](/concepts/singles) which are individual and unique.

A website using Editorial can have many different collections and singles. You can access collections on your admin panel by using the sidebar and navigating through the "collections" dropdown.
