# Working with Media Files

Editorial supports the upload of media files like images, documents, and videos. In order to upload a file to Editorial, navigate to the `Files` link on the sidebar of the admin panel and click "Upload".

## Editing images

PNG, JPEG and WebP images can be cropped, rotated and resized from the admin panel:

- In the `Files` page, hover an image and click the crop icon.
- In a file field, click the crop icon next to the selected image.

Choose the crop, rotation, width, format and quality, then click "Save copy". The edited image is saved as a new file in the same folder, the original is kept. When editing from a field, the field switches to the new image.

Some fields require a specific aspect ratio or maximum width. In that case the crop is locked to that ratio, and the field shows a warning when the selected image doesn't match, with a shortcut to edit it.
